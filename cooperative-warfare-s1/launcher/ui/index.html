Paths

Fusion co-op patch

Puts Fusion into the Spec Ops mission list and starts it in 2-player split screen. The launcher keeps your original ui.ff / patch.ff as .bak files.

Known: Player 2 is not seated in the VTOL yet and cannot be downed (revive port from MW3 in progress).

Graphics preset

The recompiled game does not accept GPU options on the command line, so the launcher writes the chosen preset into s1_sp.toml right before it starts the game. Try them in order until the white-out / flicker goes away.

The game's console output is saved to s1_run_log.txt next to the launcher - send that when something looks wrong.
